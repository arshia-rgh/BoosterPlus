# DI02 portal isolation qualification

25 September 2026. Implementation and scoped senior UI review are complete; the complete tracked commit gate and delivery receipt remain pending. DI03–DI15 and final-launch R10/R11 keep separate acceptance. No real Google consent, provider transaction or production migration was executed.

## Implemented boundary

- Explicit customer/admin/booster session, browser-binding, email challenge and Google-flow audiences; separate host-prefixed secure cookies; no role-derived cookie fallback. Staff roles do not confer staff authority on a customer session. Admin and booster first-factor-only sessions cannot enter their workspaces.
- Separate `/login`, `/admin/login`, `/booster/login`, with no public staff registration. Mandatory staff MFA, enrollment, single-use recovery, same-portal security/profile/preferences, neutral eligibility and failure guidance, coordinated email/Google progression and bounded return navigation. Sensitive actions require fresh verification and are never automatically repeated.
- Concurrent sessions coexist; local sign-out affects one session, explicitly revoking all affects every portal. Shared profile/media/conversation/notification operations use a strictly allowed audience header; native authorized streams/downloads use a non-secret query selector. Customer commerce APIs stay customer-only.
- Notification audience filtering precedes pagination and read mutation. Conversation membership keeps private customer support separate from assigned-booster coordination. Media grants bind the session. Resale delivery-secret writes use an explicit admin vault path with fresh factors rather than customer authority. Private UI state and streams are scoped/cleared by portal and identity.
- Explicit CLI SQL migration 26 invalidates legacy sessions/challenges/flows, preserves account enrollment/provider links, and rejects unscoped old writers. Down migration also revokes rather than resurrects. Ent generation remains query/schema mapping only. [Migration and callback configuration](../identity-design.md).
