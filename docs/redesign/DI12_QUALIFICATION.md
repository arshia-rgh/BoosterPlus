# DI12 editorial qualification

28 September 2026. **DI12 delivered with phase-local qualification.** DI13–DI15 continue next; R10/R11 remain held. No production content or commercial service is activated.

## Implemented scope

NW01–NW06 and SN05/SN06: per-game news, patch notes and guides; staff list/filter/create; persistent draft editor with named sections, version conflicts and leave protection; exact saved preview; reviewed immediate or UTC-scheduled publication; immutable revision/action history; cancellation, correction, unpublication, archive and restore. Explicit SQL migration 37 and Ent queries implement the domain. Server readiness requires schema 37. The worker processes durable `news.publish` jobs with live author role/security-version checks, pinned revisions and idempotent schedule tokens. Operators can see schedule state and investigate failed jobs without exposing payloads.

Public pages retain their game shell, search/type context, published/updated attribution, accessible heading/table/code/list content, related reading and recovery. Known same-game old slugs redirect only to the current released slug. Draft text never participates in public search. Public responses and private previews use no-store; private/unavailable pages are non-indexable. Configured-origin metadata and a per-game XML sitemap contain released canonical URLs only. A missing public origin fails sitemap generation closed. Public article listing batches immutable revisions rather than issuing a query for each card.

The structured editor accepts bounded plain text, safe HTTPS links and approved local artwork with alternative text/provenance. It does not accept raw HTML, embeds or arbitrary scripts. Publication requires staff review of accuracy and rights. Featured editorial cards bind an exact published article/revision, carry no price, inventory or checkout promise, and retire when that publication is revised/unpublished. Off-page selection and a clearly announced new-tab reading link keep catalog editing context intact.

Admin shop/news editor return destinations are included in the strict portal allowlist. Only known local sections survive sign-in; unknown queries, secrets, foreign origins and cross-portal routes remain excluded.
