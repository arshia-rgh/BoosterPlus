# PLAYORA brand assets

Created 13 September 2026 with the built-in image_gen tool for the owner's rebrand request. These assets establish a proposed direction for review. Application integration has not started; [the UI/UX roadmap](../../../UI_UX_ROADMAP.md#11-playora-brand-foundation-and-rollout) defines the rollout.

| Asset | Native file | Intended use |
| --- | --- | --- |
| PLAYORA logo | [playora-logo-dark.png](playora-logo-dark.png), 2172 × 724, opaque PNG | Horizontal P symbol and wordmark on a dark field; ready for standalone brand presentation. The white wordmark reads PLAYORA. |
| Aurora background | [playora-aurora-background.png](playora-aurora-background.png), 1672 × 941, opaque PNG, approximately 16:9 | Independent text-free landscape background for social artwork, covers and optional complementary marketing use. Quiet central space permits later overlays. |

The proposed identity combines a play opening and rising stroke in the P, sage-green accents, warm off-white lettering and deep forest surfaces matching the existing homepage tokens. The background uses a luminous arc and distant horizon without game characters or game logos, allowing future games to share the same brand.

Use the files separately. Preserve aspect ratio; never stretch the wordmark. The logo is **not transparent** and is not a vector master. Its dark canvas should remain part of a standalone presentation until approved transparent/light/monochrome variants are produced. The background has no embedded logo or slogan, so future social compositions can place editable copy independently. Check each crop on the actual platform before publishing; neither file is a universal social template or a 4K master. Keep these full-quality source files out of routine page downloads; web exports and responsive loading are later implementation work.

Visual inspection checked spelling, logo silhouette, padding, final edge quality, background composition and absence of unwanted text. Native size and alpha presence were checked with `sips -g pixelWidth -g pixelHeight -g hasAlpha`. Earlier distressed/checkerboard logo attempts were rejected and are not included here. The selected green PNGs are intentionally opaque. The initial cyan/violet palette was superseded by the owner’s green-theme clarification. No raster modification script was used; the selected built-in outputs were copied unchanged into this directory.

[PROMPTS.md](PROMPTS.md) records the exact generation and refinement prompts. There were no external image inputs; the logo refinements referenced earlier generated logo drafts. These are generated raster design assets, not a claim of trademark clearance or exclusive rights. Asset approval, faithful editable/vector derivatives, icon legibility, contrast, social crops and optimized web exports are explicit UX01/UX05 acceptance items.

The owner explicitly keeps the current overall green website theme, font families and background/art direction. PLAYORA changes its branding and interface details within that identity; the separate green background is reusable social artwork, not a mandatory homepage replacement. Account, chat, checkout and admin surfaces should remain restrained. R10/R11 deployment and launch work stays on hold in [final-launch.md](../../../final-launch.md).
