Keep real secrets outside Git. Point the protected deployment manifest at three separate mode-0600 runtime files based on `config/*.example`. Values use Docker's raw env-file format, never shell execution. Only the migration job receives DDL credentials; only backend processes receive authentication/vault/storage/SMTP credentials. The frontend receives the shared proxy key and approved terms. Keep backup/old vault keys independently recoverable.

Host env files and Docker container environments are readable by privileged host/Docker operators. They are not encrypted secret storage. For managed deployments, provision them with the chosen secret manager and tightly restrict host/Docker access. Do not print rendered Compose output, attach inspect output, or publish logs containing credentials. Do not place actual keys in this directory.
